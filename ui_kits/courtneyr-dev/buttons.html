04 · Components

Buttons

Sharp corners, thick borders, hard offset shadows. Active state presses the button into its own shadow — translate(2,2) + reduced shadow. Roboto Slab 700, uppercase by convention but not enforced.

Variants

.cr-button--*
Primary Secondary Outline Soft

Primary = UT Orange CTA, hovers to russian-violet · Secondary = russian-violet, hovers to cerulean · Outline = transparent, hovers to filled ink · Soft = light-orange surface

States

:hover · :active · :focus-visible
Default Hover Active Focus-visible

Active state: translate(2px, 2px) + shadow shrinks to 2×2. The button "presses into" its shadow — physical, satisfying. Focus ring is selective-yellow at 3px offset 2.
