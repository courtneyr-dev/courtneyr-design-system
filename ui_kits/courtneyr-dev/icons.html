Icon set

Eighteen post-type icons — one for each entry in the v2.1 taxonomy. Clean geometric paths in a 24×24 viewBox, currentColor stroke, 1.75 stroke-width. Loaded as a single SVG sprite from components/icons.svg. The .cr-icon-fill class on a child path opts out of stroke for filled details (e.g. the play triangle on Video).

v2.1 — what changed

redraw + 9 new
v2.1 redraw

The previous hand-drawn set was replaced with clean geometric icons in a Lucide/Feather idiom — same 24×24 viewBox, same 1.75 stroke, same currentColor contract, but with sharper, more legible silhouettes that hold up at 16px and stay recognizable as small avatars in Stream.

Metaphors

blog document · aside dog-eared note · image landscape · gallery stacked frames · video monitor + play · audio headphones · chat two bubbles · status bubble + dots · link chain · bookmark ribbon · quote curly marks · speaking microphone · book open book · like heart · repost loop arrows · reply back arrow · event calendar · review star.

Sizes

in context

16px · inline

24px · default

32px · stream avatar

48px · feature

Stroke-width is fixed at 1.75 — don't override per size. Icons are tested down to 16px; below that, drop the icon and use a text-only chip.

Avatar pattern

post-type fill

The pattern used in Stream. Background = post-type fill color, foreground = AA-passing ink. Border-thick + 2×2 ink shadow + −2.5° rotation. Avatar variants only exist for the 10 post-types whose accent passes AA against a printable foreground; the other 8 (aside, image, gallery, status, chat, repost, book, event) use the default tape chip without an avatar.
