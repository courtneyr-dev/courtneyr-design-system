January 14Review★★★★☆

Review: Eleventy as a teaching tool

Great for self-learners; tricky to onboard a junior into the build pipeline. Verdict: still recommend.

Visual rhythm: 10 types use full-color avatars (post-type fill), 8 use outline avatars (tape + accent border). Both maintain the same dimensions and rotation so the left rail stays a steady column.

Anatomy

grid: 3rem avatar + 1fr body
ElementNotes
.cr-streamWrapper · 60rem max-width
.cr-stream-itemSingle feed entry · 4px marker-bar bottom border
.cr-stream-item--{type}Optional accent on .cr-stream-item__avatar (any of 18 types)
.cr-icon-avatar--{type}Filled avatar — only for the 10 AA-safe types
.cr-icon-avatar--outlineTape-bg avatar with accent border — for the other 8 types. Set --type-color to the post-type token.
.cr-stream-item__metaDate · chip · venue / extras
.cr-stream-item__titleRoboto Slab 700, 1.25rem · marker-bar underline on hover

Hover lifts the row 2px in the negative direction (translate(-2px, -2px)) — small but readable. No scale, no fade.
