Hero

The .cr-hero primitive: a halftone-and-fiber surface with an inner column. The display, title, lead, and accent-title elements are the only required descendants. v1.x's __shape (blob shapes for layering) was removed in v2.0.

A shorter hero variant — for index-page section headers, archive lists, and tag landings. The accent title swaps to marker color for emphasis.

Anatomy

__inner / __display / __title / __lead
ElementFamilyRole
.cr-hero—Outer wrapper · halftone + fiber + ivory surface
.cr-hero__inner—60rem max-width column, centered
.cr-hero__displayRock SaltBrand-voice display heading. Once per page.

What's gone

v1.x → v2.0
Removed

.cr-hero__shape, .cr-hero__shape--1, .cr-hero__shape--2 — the floating blob shapes. Layering is now exclusively halftone + fiber + sparkle margin. See the Layering page.
