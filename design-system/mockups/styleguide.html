// body

Body text

This is a paragraph in Barlow, set at 1rem with a relaxed line-height. Inline links use cerulean and underline. Hover state shifts to russian-violet.

Inline elements: strong, em, small, mark for highlights, deleted, inserted, subscript, superscript, abbr, definition (no underline), quoted text, citation, Cmd+K, sample output, variable, inline code.

And the highlighted span — using .cr-highlight for opt-in marker treatment.
